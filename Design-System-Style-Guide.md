# Enterprise SaaS Dashboard – Design System & Style Guide

## 1. Introduction

This document explains the main design choices
I used while creating my Enterprise SaaS Analytics Dashboard.

I created the design system to keep the dashboard simple, consistent, readable, and easy to use.

## 2. Typography

I used the Inter font throughout the dashboard.

- Main headings: 24 px, Bold
- Section headings: 18 px, Semi Bold
- Body text: 14 px, Regular
- Navigation text: 14 px
- Small labels: 12 px
- KPI values: 20 px, Bold

Using the same font family helps keep all the screens visually consistent.

## 4. Components Used

I created and used reusable components for the dashboard, including:

- Navigation items
- KPI cards
- Buttons
- Date filter
- Analytics cards
- Charts
- Status indicators
- Theme toggle
- Accessibility indicators

These components help maintain the same visual style across the dashboard.

## 5. KPI Cards

KPI cards are used to show important business information at a glance.

Each card contains a label and a clear value. I used consistent
spacing, borders, and rounded corners for the cards.

## 6. Analytics Screens

The Analytics screen contains:

- Revenue Trend
- Customer Growth
- Sales by Category
- Analytics Insights
- Date Filter

I used consistent chart labels, grid lines, spacing, and colors to make the analytics easier to understand.

## 7. Layout and Spacing

I kept consistent spacing between the different sections and components.

Cards use rounded corners and borders to separate different types of information.

The dashboard layout is organized so that important information can be found easily.

## 8. Light and Dark Themes

I created both light and dark versions of the dashboard.

The light theme uses white and light-gray backgrounds with dark text.

The dark theme uses dark backgrounds with light text.

I kept the text and important elements readable in both themes.

## 9. Accessibility

While creating the dashboard, I considered:

- Readable font sizes
- Good text contrast
- Clear navigation labels
- Visible status indicators
- Consistent interaction patterns
- Readability in both themes

These choices help make the dashboard easier for different users to understand.

## 10. Prototype Interaction

I created an interactive date filter on the Analytics screen.

When the user clicks Last 30 Days, a small overlay opens with:

- Last 7 Days
- Last 30 Days
- Last 90 Days

This demonstrates the interactive prototype behavior of the dashboard.

## 11. Design Principles

The main principles I followed are:

1. Keep the information simple and organized.
2. Use reusable components.
3. Make important information easy to find.
4. Maintain good accessibility.
5. Keep both themes readable.
6. Use simple interactions.
7. Maintain consistency across all screens.

## 12. Conclusion

This style guide documents the main typography, colors, 
components, layouts, themes, accessibility considerations, and
prototype interaction used in my Enterprise SaaS Analytics Dashboard project.
