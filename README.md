# Enterprise SaaS Dashboard UX System

## About the Project

This project is an Enterprise SaaS Analytics Dashboard that I designed using Figma.

The main aim of the project was to create a clean and easy-to-use 
dashboard where users can view important business information and understand analytics easily.

## Project Objective

I wanted to create a dashboard that has:

- Simple navigation
- Clear KPI information
- Useful analytics charts
- Reusable UI components
- Light and dark themes
- Good text readability
- Simple interactions

## My Design Process

I worked on the project step by step:

1. Created the dashboard architecture.
2. Planned the main navigation and screen structure.
3. Created the design system and reusable components.
4. Designed the Dashboard Overview screen.
5. Created the Analytics screen with different charts.
6. Designed light and dark themes.
7. Added accessibility considerations.
8. Created an interactive date filter.
9. Reviewed the design through a UX audit.
10. Documented the project and created the case study.

## Dashboard Architecture

The dashboard has a simple navigation structure with:

- Dashboard
- Analytics
- Customers
- Settings

I kept the navigation simple so users can easily move between different sections.

## Design System

I created a basic design system to keep the screens consistent.

It includes:

- Typography
- Colors
- Navigation items
- KPI cards
- Buttons
- Date filter
- Charts
- Status indicators
- Theme toggle
- Accessibility indicators

I used the Inter font throughout the design.

## Dashboard Overview

The Dashboard Overview screen contains KPI cards for important information such as:

- Revenue
- Customers
- Orders

The cards help users see important values quickly.

## Analytics Screen

The Analytics screen contains:

- Revenue Trend
- Customer Growth
- Sales by Category
- Analytics Insights
- Date Filter

I used charts, labels, grid lines, and consistent spacing to make the information easier to understand.

## Light and Dark Themes

I created both light and dark versions of the dashboard.

The light theme uses white and light-gray backgrounds with dark text.

The dark theme uses dark backgrounds with light text.

I tried to keep the important information readable in both themes.

## Accessibility

While designing the dashboard, I considered:

- Readable font sizes
- Good text contrast
- Clear navigation labels
- Visible status indicators
- Easy-to-read content in both themes

## Interactive Prototype

I created an interactive date filter on the Analytics screen.

When the user clicks *Last 30 Days*, an overlay opens with:

- Last 7 Days
- Last 30 Days
- Last 90 Days

This was added to show a simple interaction in the prototype.

## UX Audit

I reviewed my dashboard to check the navigation, KPI cards, charts,
themes, accessibility, text readability, and overall consistency.

I also performed a basic self-usability review to check
whether the main information and interactions were easy to understand.
